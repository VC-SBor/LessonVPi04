# Промпт: ВК-бот с каталогом услуг детейлинг-центра

## Цель

Разработать ВК-бота на языке Python с использованием библиотеки vkbottle, который предоставляет пользователям каталог услуг детейлинг-центра.

Для обработки входящих сообщений необходимо использовать Long Poll API.

## Технологии

- Python 3.11+
- vkbottle
- Long Poll API VK
- Keyboard API (Callback-кнопки)
- JSON (для хранения каталога услуг отдельно от кода — по желанию)

## Структура проекта

```
detailing_bot/
├── bot.py
├── config.py
├── services.py
├── keyboards.py
└── requirements.txt
```

## Каталог услуг

### 1. Комплексная мойка

**Стоимость:** 1500 руб.

**Описание:**
Полная мойка кузова, дисков, стёкол, дверных проёмов и сушка автомобиля.

### 2. Химчистка салона

**Стоимость:** 7000 руб.

**Описание:**
Глубокая очистка сидений, потолка, пола, дверных карт и пластиковых элементов. Удаление сложных загрязнений и устранение запахов.

### 3. Полировка кузова

**Стоимость:** 12 000 руб.

**Описание:**
Восстановительная полировка лакокрасочного покрытия: удаление мелких царапин, голограмм и окислов, возврат блеска и глубины цвета кузова.

### 4. Керамическое покрытие

**Стоимость:** 25 000 руб.

**Описание:**
Нанесение защитного керамического слоя на кузов: защита от реагентов, грязи и мелких царапин, гидрофобный эффект и стойкий глянец на срок до 1–2 лет.

### 5. Антидождь

**Стоимость:** 3000 руб.

**Описание:**
Защитное покрытие стёкол для улучшения видимости во время дождя: капли скатываются с поверхности даже без работы дворников.

## Главное меню

После запуска бот отправляет сообщение:

> Добро пожаловать в детейлинг-центр DetailPro!
> Выберите интересующий раздел

### Кнопки

- Услуги
- Прайс-лист
- Связаться с менеджером

## Функциональность

### 1. Главное меню

Отображается после получения одного из сообщений:

- «Начать»
- «Привет»
- «start»

### 2. Список услуг

После нажатия кнопки «Услуги» бот показывает список:

- Комплексная мойка
- Химчистка салона
- Полировка кузова
- Керамическое покрытие
- Антидождь

Каждая услуга — отдельная кнопка клавиатуры.

### 3. Описание услуги

После выбора услуги бот выводит информацию, например:

> Комплексная мойка
>
> Полная мойка кузова, дисков, стёкол, дверных проёмов и сушка автомобиля.
>
> Стоимость: 1500 руб.

После сообщения отображаются кнопки:

- Назад
- Главное меню

### 4. Прайс-лист

После нажатия кнопки «Прайс-лист» бот выводит:

> Прайс-лист
>
> Комплексная мойка — 1500 руб.
> Химчистка салона — 7000 руб.
> Полировка кузова — 12 000 руб.
> Керамическое покрытие — 25 000 руб.
> Антидождь — 3000 руб.

После сообщения отображается кнопка:

- Главное меню

### 5. Связь с менеджером

После нажатия кнопки «Связаться с менеджером» бот отправляет сообщение:

> Наш менеджер ответит вам в ближайшее время.
>
> Телефон:
> +7 900 123-45-67
>
> Или напишите в сообщения сообщества.

После сообщения отображается кнопка:

- Главное меню

## Логика работы

```
Главное меню
├── Услуги
│   ├── Комплексная мойка
│   ├── Химчистка салона
│   ├── Полировка кузова
│   ├── Керамическое покрытие
│   └── Антидождь
├── Прайс-лист
└── Связаться с менеджером
```

Кнопка «Назад» возвращает к списку услуг, «Главное меню» — в главное меню из любого раздела.

## Требования к реализации

Необходимо использовать:

- библиотеку vkbottle;
- подключение к VK через Long Poll API;
- клавиатуры VK (Keyboard);
- обработчик сообщений (`@bot.on.message`);
- отдельный модуль для хранения каталога услуг (`services.py`);
- отдельный модуль с клавиатурами (`keyboards.py`);
- токен и идентификатор группы — в отдельном модуле `config.py` (не хардкодить в основном коде).

## Ожидаемый результат

После запуска бот должен:

- приветствовать пользователя;
- отображать главное меню;
- показывать каталог услуг;
- выводить описание выбранной услуги с ценой;
- отображать прайс-лист;
- предоставлять кнопку для связи с менеджером;
- обеспечивать удобную навигацию с возвратом в главное меню;
- корректно реагировать на повторные нажатия кнопок и неизвестные сообщения.
