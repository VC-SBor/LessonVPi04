# DetailPro — ВК-бот детейлинг-центра

Бот для сообщества ВКонтакте: показывает услуги, прайс-лист и контакты менеджера.
Работает на Long Poll API (для разработки нужен только Python и интернет, сервер не нужен).

## Как бот работает с сообщениями

- на экране у пользователя всегда **только одно сообщение бота**;
- перед отправкой нового сообщения предыдущие **удаляются** — ленты из сообщений нет;
- после нажатия кнопки бот **сразу** отвечает на событие (snackbar), поэтому на кнопке
  не залипает вращающийся круг;
- **при каждом запуске бота удаляется вся история его сообщений** во всех диалогах —
  прошлый диалог не мешает начать заново.

## Требования

- Python 3.10 или новее;
- сообщество ВКонтакте с включённым Long Poll API.

## Настройка сообщества ВКонтакте

1. **Ключ доступа**: Настройки сообщества → Работа с API → Ключи доступа →
   создать ключ. Нужны права: «Сообщения сообщества» (Messages) и управление.
2. **Long Poll API**: Настройки сообщества → Работа с API → Long Poll API →
   включить, версия API — `5.131`.
3. **Идентификатор сообщества**: Настройки сообщества → Основная информация →
   Идентификатор сообщества (без минуса).
4. В настройках сообщества → Сообщения → включить «Возможность писать сообществу».

## Конфигурация

В папке бота скопируйте шаблон `.env.example` в `.env` и подставьте свои значения:

```powershell
copy detailing_bot\.env.example detailing_bot\.env
```

Содержимое `.env`:

```env
VK_TOKEN=сюда_ваш_ключ_доступа_сообщества
GROUP_ID=идентификатор_сообщества_без_минуса
```

Файл `.env` содержит секрет — не публикуйте его и не добавляйте в git.

## Установка и запуск

### Windows (PowerShell)

Из корня проекта:

```powershell
# 1. Виртуальное окружение (создаётся один раз)
python -m venv venv

# 2. Активация окружения
venv\Scripts\Activate.ps1

# 3. Установка зависимостей (один раз)
pip install -r detailing_bot\requirements.txt

# 4. Запуск бота
python bot.py
```

Или из папки `detailing_bot`:

```powershell
cd detailing_bot
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bot.py
```

### Linux / macOS

Из корня проекта:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r detailing_bot/requirements.txt
python bot.py
```

Или из папки `detailing_bot`:

```bash
cd detailing_bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

При старте в консоли появятся сообщения:

```text
Бот DetailPro запускается...
Очищаю историю сообщений бота...
Очистка завершена, удалено сообщений: N
```

После этого бот работает и отвечает на сообщения.

## Остановка бота

Остановить бота — в консоли, где он запущен:

```text
Ctrl + C
```

Бот корректно завершит работу (сообщения уже отправленные остаются в диалоге,
но при следующем запуске будут удалены автоматически).

Чтобы бот работал постоянно (не только пока открыта консоль), запускайте его
под управлением планировщика задач (Windows Task Scheduler) или `systemd` (Linux),
либо в фоне через `nohup python bot.py &`.

## Проверка работы

1. Запустите бота (`python bot.py`).
2. Напишите сообществу «Привет» — бот ответит приветствием с кнопками:
   «Услуги», «Прайс-лист», «Связаться с менеджером».
3. Нажмите любую кнопку — предыдущее сообщение исчезнет, появится новое.
4. Нажмите «Главное меню» — вернётесь к приветствию.

## Возможные проблемы

| Симптом | Причина / решение |
|---|---|
| `Invalid token` или пустые ответы | Неверный `VK_TOKEN` в `.env` |
| `GROUP_ID` — ошибка при запуске | В `GROUP_ID` должно быть число без минуса |
| Бот молчит | Проверьте, что Long Poll API включён и версия `5.131` |
| Сообщения старше суток не удаляются у всех | ВК разрешает удалять «для всех» только свежие сообщения; старые бот удаляет у себя |
| Ошибка при активации `venv\Scripts\Activate.ps1` | Выполните `Set-ExecutionPolicy -Scope Process RemoteSigned` или запускайте через `cmd`: `venv\Scripts\activate.bat` |
